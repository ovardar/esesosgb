# Teklif ve Sözleşme Yönetimi

Bağımsız bir teklif, sözleşme, müşteri, doküman, fiyat listesi ve yetkilendirme uygulaması için başlangıç workspace'i.

## Başlangıç

- `npm install`
- `npm run dev`
- `npm run build`

## Kapsam

- Müşteri kayıtları ve ilişkili ticari bilgiler
- Teklif oluşturma ve takip
- Sözleşme yönetimi
- Doküman yükleme ve ilişkilendirme
- Fiyat listeleri
- Rol tabanlı yetkilendirme
